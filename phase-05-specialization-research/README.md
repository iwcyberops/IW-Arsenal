## 🛠️ Software Engineering & Research Standards

All research tools, patches, and exploit harnesses authored in Phase 05 represent publication-grade software engineering:

1. **Upstream Patch Engineering:** Security patches submitted to upstream projects (Linux Kernel / Chromium) adhere strictly to lock-free atomic checks, compile-time assertions, and introduce zero throughput regressions.
2. **Deterministic Exploit Reliability:** PoC triggers operate reliably in clean virtual testbeds outside the instrumentation environment without reliance on non-deterministic memory states.
3. **Responsible Disclosure Coordination:** All discovered vulnerabilities are packaged according to international coordinated vulnerability disclosure standards (ISO/IEC 29147).
